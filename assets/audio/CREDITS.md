# Audio credits

Every sound effect and music loop in this folder is original. Each one is synthesised from oscillators and noise by `tool/generate_audio.py`, with fixed seeds, so the files can be rebuilt exactly. No third-party samples, loops or presets are used, so there is nothing to attribute.
