# Decisions

One line per decision: date, decision, reason.

- 2026-11-11: Treat this folder as a fresh start. It contains only the unmodified Flutter template.
- 2026-11-11: Author an original Classic Sunshine layout instead of the listed jumps. The listed jumps are the published Chutes and Ladders board, and they also miss the 25-40 turn target.
- 2026-11-11: Leave `web/`, `macos/`, `linux/` and `windows/` untouched and unsupported. The app targets Android and iOS only.
- 2026-11-11: Fresh start; sibling projects are not audited or reused. User instruction.
- 2026-11-11: Minimum Android is API 24, not 23. Current `flutter_secure_storage` and `shared_preferences` require 24, and the user approved it.
- 2026-11-11: App name Dice Party, bundle id `com.dawnplay.diceparty`, package `dice_party`. User accepted the defaults.
- 2026-11-11: Use the existing git repository on `main` (user's initial commit and GitHub remote). Assets and goldens must be committed.
- 2026-11-11: Flame renders both boards and in-board effects; Flutter widgets handle menus and HUD. One rendering approach for both games, shared effects and animation queue.
- 2026-11-11: Split `GameModule` (pure Dart) from `GamePresentation` (routes, screens). The brief's route builder cannot sit in a domain layer that must not import Flutter.
- 2026-11-11: Add `removePlayer`, `updatePlayer` and `statsFor` to `GameModule`. Sessions need them to stay free of game-specific branches.
- 2026-11-11: Theme and shared game widgets live in `platform/`, not `app/` or `shell/`. Games sit below the shell and must be able to import them without an upward dependency.
- 2026-11-11: `LocalSession` and `HostSession` share one `AuthoritySession`. Timer, auto-move and AI logic then cannot differ between local and Wi-Fi.
- 2026-11-11: An S&L roll resolves the whole move in one `apply`, so its `autoIntent` is always null. The protocol has no S&L intent other than roll.
- 2026-11-11: `turnSeq` increments on every accepted intent, so it identifies a decision point. Double taps and stale intents are then rejected without phase-specific checks.
- 2026-11-11: Use `nsd` for Bonjour and send UDP beacons on Android only. iOS UDP broadcast needs an Apple-granted entitlement and raw-socket mDNS has the same limit.
- 2026-11-11: Pong goes only to the socket that pinged. Broadcasting it would multiply heartbeat traffic with no benefit.
- 2026-11-11: Online games use the host's animation speed, and clients compress backlog. A Fast host would otherwise outrun a Normal client.
- 2026-11-11: Commit generated `.freezed.dart` and `.g.dart` files. A clean checkout can then run `flutter analyze` without a build step.
- 2026-11-11: S&L layouts for all three boards live in `design/boards/*.json`, generated by `tool/design/design_snl_boards.py` and verified by `tool/design/check_snl_boards.py`. They are original, pass the validator rules, keep snake bodies at least 0.089 board units clear of other starts, and give 26.1-37.7 mean turns (2 players, first winner) at 6-8 snakes.
- 2026-11-11: No jump starts on square 1 or ends on 100. This avoids the need-a-6 and ladder-on-1 interaction.
- 2026-11-11: Wireframes are generated by `tool/design/build_wireframes.py` (with `wf_lib.py`, `wf_screens.py`) from the board JSON and the §3.1 geometry, so the drawn boards cannot drift from the data. Published privately as an artifact.
- 2026-11-11: S&L start pad (position 0) sits under square 1, outside the board, because the board fills the screen width.
- 2026-11-11: Phase 3 art was drawn from the brief's written palettes and style notes because `ref/` was never provided.
- 2026-11-11: SVG sources live in `art/` (mirroring `assets/`) so they are not bundled into the app; PNGs at 1x/2.0x/3.0x live in `assets/`. Built by `tool/export_assets.py` with `@resvg/resvg-js` and the bundled fonts.
- 2026-11-11: Board JSON is copied from `design/boards/` into `assets/games/snakes/boards/` by the exporter; `design/boards/` stays the source of truth.
- 2026-11-11: Music OGG uses the native ffmpeg Vorbis encoder at quality 1, 22.05 kHz (136-144 KB). Quality 0 produces silence, so the build now decodes every file and fails on silence or on any file over 150 KB.
- 2026-11-11: Music M4A uses HE-AAC 16 kbps mono (130 KB). Audio generation needs macOS for the `aac_at` encoder.
- 2026-11-11: Ludo token edges, not fills, carry the 3:1 contrast: yellow fill is 1.6:1 on white, so tokens rely on the dark-tint outline (light) or white rim (dark) plus the colour-blind symbol.
- 2026-11-11: Hub card art fades to the card colour over its left 42% so titles and the Continue chip never sit on the illustration.
